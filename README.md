
# Recipe Box

## About the App
Recipe Box is a simple recipe management website that allows users to discover, save, and manage their favorite recipes in one place. It helps users organize recipes and easily access cooking instructions and ingredients.

## Features
- **User Registration and Login** – Allows users to create an account and log in.
- **Search Recipes** – Helps users find recipes using the search bar.
- **Recipe Categories** – Organizes recipes into different categories.
- **View Recipe Details** – Displays ingredients and cooking instructions.
- **Favorites** – Allows users to save their favorite recipes.
- **My Recipes** – Allows users to add, edit, and delete their own recipes.
- **User Profile** – Displays account information and provides a logout option.

## How to Run the App
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if you don't have it.
4. Right-click `index.html` and select **Open with Live Server**.
5. Make sure you have an internet connection to access Firebase services.
